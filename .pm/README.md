# .pm — internal PM notes

Internal product-management working notes and milestone logs for maintainers. This is **not documentation** — see [`README.md`](../README.md) and [`SECURITY.md`](../SECURITY.md) for the real thing. Content here may be stale, aspirational, or reference unshipped work.

Before proposing or materializing roadmap work, read [`DO_NOT_DO.md`](./DO_NOT_DO.md) and treat it as a hard constraint.

Every `wN` worker is general-purpose and may take work anywhere in the bex-security project. A workstream directory records scheduling and history only; it does not define a permanent mission, specialty, component boundary, or ownership claim.

`/pm` is the only skill that writes here; its conventions live in [`.claude/skills/pm/SKILL.md`](../.claude/skills/pm/SKILL.md). `/pm-brainstorm` proposes work as text; `/loop-worker <wN>` drains a workstream milestone by milestone, shipping each with `/ship`.
