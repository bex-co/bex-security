## Objective

Reuse Bex's existing worker queue to split large inventories into bounded ACP review assignments when an agent lacks delegated workers, without branching on the Muse agent name.

## Context

- Muse preflight reports delegated workers unavailable and a single long prompt tends to perform shallow grep-based sampling.
- `component-scan.ts` already has bounded concurrency, per-component outputs, retries, and aggregation patterns.
- The fallback must be selected from negotiated capability, not an agent-specific code path.

## Steps

1. Partition the authoritative inventory by component/security boundary and bounded input size.
2. Run assignments through independent ACP sessions with bounded concurrency and exact assigned paths.
3. Validate each assignment's reviewed-file result and requeue missing or failed work.
4. Aggregate candidates for independent validation and final host-owned coverage.
5. Preserve the existing `scan --agent <name>` command and defaults.

## Acceptance criteria

- [ ] Any ACP agent without delegated-worker capability uses the same host fallback.
- [ ] Missing files are retried and leave coverage partial if recovery is exhausted.
- [ ] Progress is computed from accepted assignments, not elapsed time or model claims.
- [ ] Agents with working delegation retain their existing path.

## Out of scope

- Artificially delaying a scan to meet a target duration.
